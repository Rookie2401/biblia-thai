# Biblia — ไทย

The Thai Bible (the Biblica® Open Thai Common Version™, 2025) in Biblia, read through GoLearn: every word can be tapped for its meaning and grammar, and, when you sign in with your GoLearn
account, what you look up is recorded under your Thai enrolment for review in GoReview.

Live at https://rookie2401.github.io/biblia-thai/

This repository holds only the built site. It is built from the go-v0 source (`packages/biblia`, `npm run biblia:build-standalone-th`);
each commit names the source commit it was built from.
